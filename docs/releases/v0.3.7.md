# Weave 0.3.7

Local Imagine Workspace is now **Weave**, with the approved White Flame icon and gold/red stars across the app and Windows packaging.

The interface, dialogs, browser title, Codex identity, executable, and installer use the new name. Existing projects remain compatible, and the app retains the previous profile location and installer identity for upgrades.

Run **Weave Setup 0.3.7.exe** to install the Windows x64 app. The installer is unsigned. The production build, 51 unit tests, browser integration check, and packaged-app smoke check passed. See [verification notes](https://github.com/Wrathalan/GenBoard-Workspace/blob/v0.3.7/docs/verification.md) for details and checksum.
