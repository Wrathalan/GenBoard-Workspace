# Weave 0.3.9

Switch between boards more quickly and create or rename them without leaving the canvas.

- Search the current project's boards from the header or with **Ctrl+Shift+B**, then use arrow keys and Enter to select a board.
- Name boards before creating them, and rename the current board from the switcher or Inspector.
- Return to the previous board with the header arrow, preserving saved content, pan, and zoom.
- Keep search available while a Codex turn runs, with a clear explanation when navigation is blocked.
- Create and activate boards atomically, retain entered names after failures, and prevent duplicate submissions.

Download **Weave.Setup.0.3.9.exe** for Windows x64. The installer is unsigned and uses the existing application identity and profile location. Verify the download with **SHA256SUMS.txt**. No inference models or user account data are bundled.

Validation: all 53 unit tests, all 29 Electron desktop scenarios, and the real-backend browser integration passed. TypeScript, the production build, and the packaged-app smoke check passed. Detailed results are recorded in `docs/verification.md`. Automated Codex tests use a synthetic provider; authenticated generation and third-party website uploads are not part of release validation.
