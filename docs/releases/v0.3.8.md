# Weave 0.3.8

Open websites beside your canvas and drag original images into their attachment areas.

- **Workspace browser:** a desktop panel with an address bar, back/forward navigation, reload/stop, and a separate persistent website session.
- **Image attachments:** globe drag handles on canvas images and library thumbnails; select multiple library images to attach them together.
- **Workspace isolation:** website content has no workspace API access, and the browser panel hides behind workspace dialogs and during safe screenshots.

Download **Weave-Setup-0.3.8.exe** for Windows x64. Existing projects and settings remain compatible. The installer is unsigned.

Websites must support file drops, and their attachment limits apply. Some websites restrict embedded-browser sign-in. Automated attachment checks verify original file payloads and Chromium file drops; Windows' interactive OLE drag loop and third-party sign-in/uploads were not tested.

The production build, all 53 unit tests, all 25 desktop scenarios, external-browser integration, and the packaged-app smoke check passed. See [verification notes](https://github.com/Wrathalan/GenBoard-Workspace/blob/v0.3.8/docs/verification.md) for details and checksum.
