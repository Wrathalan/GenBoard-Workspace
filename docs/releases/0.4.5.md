# Weave 0.4.5 — Quality-of-life update

- Resize the Codex and workspace browser panels by dragging their inside edges. Widths are remembered.
- Keep board tabs in a fixed order through saves, renames, switching, and reopening. Use the grip button for explicit manual reordering. Tabs now use a pill style.
- Import Chrome or Firefox bookmarks and recent history from a selected browser profile. Passwords, cookies, and signed-in sessions are not imported.
- Show a complementary Codex panel tint while working and a stronger Your turn alert when a reply finishes.
- Reduce chat rendering overhead by batching streamed text updates.
- Remove optional image-provider discovery from the request send path, avoiding a possible 60-second delay before Codex starts. Show preparation, thinking, image generation, history compaction, and response timing when available. Model inference speed itself has not been benchmarked.
- Keep automatic Codex reconnection notifications from pausing a recovering queue; improve image-generation availability messaging.
- Organize project-wide reference objects in Character, Attire, and Environment categories, with editable names and details and migration from existing board references.

## Download and update

Download **Weave.Setup.0.4.5.exe** from this release and run it to update. Existing updater-enabled installations can use the in-app update notification. Keep the installer, blockmap, latest.yml, and SHA256SUMS.txt together in the release for updater compatibility.

Windows x64. The installer is unsigned. Save your project before updating. No live image generation or real installed-version auto-update was performed during verification.
