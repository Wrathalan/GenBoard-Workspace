# Local Imagine Workspace 0.3.5

Privacy refresh: the installer was rebuilt with a generic style preset, documentation now uses a generic project path, and a screenshot containing a private project-folder name was replaced. The published source history was sanitized. Download this refreshed installer if you downloaded an earlier copy.

First release published to GenBoard Workspace, collecting the current desktop application and local browser mode.

## Highlights

- Organize images, notes, and named groups on an autosaving canvas with grid and alignment snapping.
- Move an entire group by dragging any member, preserving nested layouts and respecting locked members.
- Open the workspace through a loopback-only browser server using the same local project storage.
- Choose full application themes and customize individual card colors.
- Mark sensitive canvas items and copy a masked canvas screenshot in the desktop app.
- Use recent-project navigation, optional Codex chat/imagegen, and an existing local ComfyUI installation.
- Read illustrated workflow explanations using three supplied artwork screenshots and one synthetic test screenshot in the README.

## Download and install

Download **Local Imagine Workspace Setup 0.3.5.exe** and run the Windows x64 installer. Installation is per-user and supports choosing a destination folder. The installer is unsigned. No models, ComfyUI installation, or example artwork are bundled. Codex is an optional online integration requiring a separate sign-in.

Verify the download against **SHA256SUMS.txt**, for example with PowerShell `Get-FileHash -Algorithm SHA256`.
