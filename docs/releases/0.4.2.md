# Weave 0.4.2

Keep character, attire, and environment references close at hand without adding cards to your board.

## What's new

- **Floating reference tray:** References sit at the top left inside the workspace viewport and stay in place while you pan and zoom. Collapse the tray from its heading when you need more viewing room; Weave remembers that choice.
- **Three reference tabs:** Character opens first, followed by Attire and Environment. Each board saves its own reference images in each category.
- **Easy reference collection:** Import images, drop files or reference thumbnails, or copy selected canvas images with **Add selected**. Click to preview, drag a thumbnail into Codex, and remove references without deleting the original images.
- **Keyboard support:** Move between tabs with Left/Right or Home/End. Tray interactions leave board shortcuts alone, and safe canvas screenshots exclude the tray.

## Installing and updating

Download **Weave.Setup.0.4.2.exe** and run it to upgrade. Installed 0.4.1 builds can receive this release through the top-bar updater once it is published. Older builds require a manual upgrade. Project folders, preferences, and the existing Codex profile are preserved.

The installer is unsigned. `SHA256SUMS.txt` contains its SHA-256 checksum. The `.blockmap` and `latest.yml` files support in-app updates and do not need to be opened manually.
