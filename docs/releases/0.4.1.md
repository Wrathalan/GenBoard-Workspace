# Weave 0.4.1

This patch improves board organization, precision, and recovery, and adds GitHub updates inside Weave.

## What's new

- **Updates in the top bar:** A small notification appears when a newer stable release is available. Click to download, then choose **Restart to update**. Weave saves edits first and waits for active generation and queued Codex tasks to be resolved.
- **On-board folders:** Create, name, collapse, expand, and nest folders. Drag cards into them while retaining their layout, with undo/redo and saved state.
- **Send to menus:** Right-click cards or groups to move them into a folder or copy them to another board through searchable destination lists.

## Fixes and improvements

- **More precise alignment:** Edge-to-edge dragging favors the joined neighbor, while resizing preserves image proportions and the opposite anchor. Fractional dimensions no longer introduce small gaps or drift.
- **Copy/paste between boards:** Ctrl+C and Ctrl+V carry selected images, notes, groups, and folders across boards in the same project session, preserving layout and internal edge links. Pasting supports undo/redo.
- **Queue recovery:** After a generation failure, your next reply runs ahead of pending tasks. A successful reply resumes the queue automatically. Further failures keep it paused; manual Pause and Stop still require Resume.

## Installing and updating

Download **Weave.Setup.0.4.1.exe** and run it to upgrade. Existing 0.4.0 and older installations need this one manual upgrade to receive in-app updates. Project folders, preferences, and the existing Codex profile are preserved.

The installer is unsigned. `SHA256SUMS.txt` contains its SHA-256 checksum. The `.blockmap` and `latest.yml` assets support future in-app updates; they do not need to be opened manually.

## Verification

Validated with 75 unit tests, 39 desktop scenarios, browser integration, and packaged application/updater smoke checks. Details are recorded in [docs/verification.md](https://github.com/Wrathalan/GenBoard-Workspace/blob/v0.4.1/docs/verification.md). Updater transport testing uses a local feed and inert download fixtures; authenticated live generation and an actual installed-version update have not been exercised. The browser version does not install desktop updates.
